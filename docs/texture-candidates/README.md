# Texture candidates

One screenshot per candidate, rendered in `/lab` with the game's own lighting
(sunlit/overcast mood 0.35, moss turned down so floors stay visible).
File names: `<category>--<asset id>.jpg`. All assets are CC0 (Poly Haven / ambientCG).

Current picks (`src/config/materials.json`) are my defaults; change them in `/lab`
(★ Pick, then "Export picks" and paste the JSON to me, or run `npm run dev` locally
and the Pick button writes the file directly).
